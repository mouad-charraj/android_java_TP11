# TP Geolocalisation Android - PHP/MySQL

Realise par : CHARRAJ Mouad

## Description

Application Android de geolocalisation connectee a un backend PHP/MySQL.

## Structure

- frontend/ : projet Android complet
- backend/ : serveur PHP + dashboard
- demo/ : video de demonstration

## Lancement

### Serveur
1. Copier le contenu de backend/ dans xampp/htdocs/localisation/
2. Demarrer Apache et MySQL
3. Ouvrir http://localhost/localisation/init_db.php

### Android
1. Ouvrir frontend/ dans Android Studio
2. Lancer l'application
3. Appuyer sur "Envoyer Position"
